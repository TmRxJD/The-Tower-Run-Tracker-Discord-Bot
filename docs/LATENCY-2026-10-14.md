## Repairs

- Main history pages are 500 rows; extended ID batches remain 100 IDs and run in waves of four. Pagination, final-count consistency, schema, ownership/profile checks, shared deadline and single consistency retry remain intact. A failed wave drains before the reader is released; no later wave starts.
- Review creation uses the verified read-only history view and avoids rewriting every historical local record. Submission retains a new complete verification inside its mutation lock. Share also verifies fresh history.
- No completed-history cache was introduced. There is no reliable cross-instance/website invalidation signal, so a session snapshot alone cannot establish current edits or deletions. Existing coalescing of unfinished reads is retained.
- Content-free, logger-rate-limited operation timings distinguish lock wait, cloud history, local reads, hydration, save, ordered presentation, and share settings/render/snapshot/payload/send/finalization on natural traffic.

## BH/orb comparison

The current report parses the corrected effect-active BH/orb counts. The recent cloud record retains those fields. Earlier history lacks an eligible corrected baseline in the tested modes. Previous patches showed a special `(comparison unavailable)` annotation for BH/orbs, while ordinary metrics could include the just-saved selected run as their own reference and display a misleading `(+0.00%)`.

The shared platform patch now excludes the selected run for every metric and uses one reference-selection/fallback rule. BH/orbs still compare only actual effect-active counts; old hit counts are not fabricated into the new measurement. Missing/unusable baselines and zero denominators produce no relative-change annotation, consistently with other metrics. Explicit current zero coverage remains `0%`; a genuine unchanged valid comparison remains `(+0.00%)`. New report effect-active zero values are tested against nonzero hit counts to ensure the old values do not override them.

The package patch and its SHA-256 lockfile references were updated. Applying it to a reconstructed unpatched package reproduces all eight modified files modulo Windows line endings. No schema/index, credential, security, or network configuration changes were made.
